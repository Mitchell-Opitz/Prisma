# Prisma

**Bend the Light.**

A single-player puzzle game. Control various pieces to direct beams of light to the correct color target. Clear all targets on the level to win.

[![Play on itch.io](https://img.itch.zone/aW1hZ2UvMTM4Njg1NC84MDgwMDIyLmpwZw==/original/IKY1Yi.jpg)](https://brainfartstudio.itch.io/prisma)

---

## About

This game was created for [One Minute Game Jam #5](https://itch.io/jam/one-minute-game-jam-5), my first game jam. The initial idea was much larger, but I narrowed the scope due to the short deadline. Possible future upgrades include a prism that splits white light into all other colors, portals that change a beam's position and direction, windows that only allow a certain color through, pistons to reveal new parts of the level, and wires to see what "doors" a target controls.
