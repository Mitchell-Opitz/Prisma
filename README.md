# Prisma

![Gameplay](https://img.itch.zone/aW1hZ2UvMTM4Njg1NC84MDgwMDIyLmpwZw==/original/IKY1Yi.jpg)

Prisma is a single-player puzzle game.  Control various pieces to direct beams of light to the correct color target.  Clear all targets on the level to win.

Dev notes: This game was my submission for [One Minute Game jam #5](https://itch.io/jam/one-minute-game-jam-5) (my first game jam!).  The initial idea was much larger, but I narrowed down scope due to the short deadline.  Possible future upgrades:

  - A prism that splits white light into all other colors (this was my original idea, but just changed the color of the current beam for the jam).
  - Portals that change a beam's position and direction.
  - Windows that only allow a certain color through.
  - Pistons to reveal new parts of the level.
  - Wires to see what "doors" a target controls.
